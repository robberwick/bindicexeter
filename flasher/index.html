bindicexeter flasher

Wemos S3 Mini (ESP32-S3, 4 MB). Needs Chrome or Edge on a desktop — Web Serial is not available in Firefox or Safari.

e.g. main or pr-123. Leave “Erase device” unchecked in the dialog to keep the WiFi/UPRN config already on the board; the image only writes the bootloader, partition table and app.

Device config

A blank board has no filesystem: after installing, the firmware formats one and waits up to two minutes on USB serial for this form. To change the config later, install again with “Erase device” checked, then send it here.
