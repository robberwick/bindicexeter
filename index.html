bindicexeter flasher

Wemos S3 Mini (ESP32-S3, 4 MB). Needs Chrome or Edge on a desktop — Web Serial is not available in Firefox or Safari.

1. Install firmware

  1. Plug the board in with a USB data cable.
  2. Press Install and pick the serial port.
  3. Leave “Erase device” unchecked to keep an existing config; tick it to wipe the config and start over.

Build e.g. main, pr-123

The install dialog shows the build version. If it is not the one you expected, reload this page.

2. Send device config

Only after a first install or an erase: the board restarts, formats its filesystem and waits up to five minutes for this form. Fill it in and press Send config over USB; the board replies “OK config.json saved” and carries on booting. On later firmware updates, skip this step.

No reply? Press the board's RST button, then send again. A board that already has a config does not wait, so tick “Erase device” in step 1 first if you want to change it.
