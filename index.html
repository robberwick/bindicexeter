Wemos S3 Mini (ESP32-S3, 4 MB). Needs Chrome or Edge on a desktop — Web Serial is not available in Firefox or Safari.

e.g. main or pr-123. Leave “Erase device” unchecked in the dialog: this image only writes the bootloader, partition table and app, so the WiFi/UPRN config in LittleFS survives.
